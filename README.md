### Sobre mí

Desarrollo aplicaciones con C# y .NET, sobre todo con Blazor Server. Buena parte de mi trabajo es conectar sistemas que no se hablan entre sí: sincronizar datos entre plataformas, automatizar procesos que se hacían a mano y mantener servicios en la nube que tienen que seguir funcionando sin que nadie los vigile.

Me gusta que el código se pueda mantener dentro de un año, no solo que funcione hoy.

Ahora mismo estoy ampliando hacia desarrollo móvil con Kotlin y Flutter.

### En qué me centro

- Aplicaciones web con Blazor Server y .NET
